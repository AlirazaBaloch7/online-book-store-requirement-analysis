# 📖 Project Overview

This repository contains the **Requirement Analysis documentation** for the **Online Book Store Enterprise Platform**, developed as part of a **Software Quality Assurance (SQA)** assignment.

The project demonstrates the process of analyzing business requirements and converting them into structured documentation suitable for software development and testing.

---

# 🎯 Objectives

- Analyze business requirements
- Define Functional Requirements
- Define Non-Functional Requirements
- Create User Stories
- Write Acceptance Criteria using Gherkin Syntax
- Prepare Sprint Planning
- Produce an enterprise-quality Software Requirements Specification (SRS)
